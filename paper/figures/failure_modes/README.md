# Failure-Mode Figure Guide

These figures are exploratory artifacts for the failure-mode taxonomy. They are
generated by:

```bash
python -m experiments.run_failure_modes --toy
```

They are deterministic toy checks, not trained-network evidence.

## Figures

`beta_failure_toy.png`

Shows three beta-bridge toy regimes. The weakly correlated reference has
`beta_fit / mean(r^2)` near one. The high-leverage hard sample overestimates mean
residual energy. The low-leverage hard sample underestimates it.

`pair_failure_toy.png`

Compares global `A_pair` against the pushed pair proxy. The high-gain bad
direction makes both diagnostics large. The low-gain bad direction keeps global
`A_pair` large while suppressing the pushed proxy.

`regime_map.png`

Places conceptual regimes on two diagnostic axes: absolute leverage-residual
covariance and high-gain pair defect. It is a visual taxonomy, not a measured
trained-network scatter plot.

## Interpretation

The point of these figures is to separate distinct failure mechanisms:

1. beta bridge failure from leverage-residual coupling
2. weighted-law failure from high-gain pair defects
3. raw-law failure from beta collapse

The next step is to compare these toy regimes against trained synthetic families
such as rare-region outliers, two-region gating, clustered Gaussians, and
mixtures of subspaces.
